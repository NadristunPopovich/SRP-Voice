# Политика конфиденциальности SRP Voice **Дата обновления:** 30 сентября 2026 года ## 1. Общие положения SRP Voice — Discord-бот для создания и управления временными голосовыми каналами. ## 2. Какие данные обрабатываются Для работы функций бота могут обрабатываться: * Discord ID пользователей; * Discord ID серверов; * Discord ID голосовых и текстовых каналов; * информация о подключении пользователей к временным голосовым каналам. ## 3. Использование данных Данные используются исключительно для работы функций бота, включая создание, управление, удаление временных голосовых каналов и ведение технических логов. Персональные данные не продаются и не передаются третьим лицам для рекламных целей. ## 4. Хранение данных Бот не предназначен для постоянного хранения личной информации пользователей. Технические данные используются только в объёме, необходимом для работы соответствующих функций. ## 5. Безопасность Мы принимаем разумные меры для защиты обрабатываемой информации от несанкционированного доступа. ## 6. Изменения политики Политика конфиденциальности может периодически обновляться. Актуальная версия всегда размещается на данной странице. ## 7. Контакты По вопросам конфиденциальности и работы SRP Voice можно обратиться к разработчику через официальный сервер поддержки.
