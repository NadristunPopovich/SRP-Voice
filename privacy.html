Политика конфиденциальности

Последнее обновление: 30 сентября 2026 года

1. Общие положения

SRP Voice — Discord-бот для создания и управления временными голосовыми каналами на серверах Discord.

Настоящая политика описывает информацию, которая может обрабатываться ботом в процессе его работы.

2. Какие данные обрабатываются

Для работы функций SRP Voice может использовать следующие технические данные:

  • Discord ID пользователей;
  • Discord ID серверов;
  • Discord ID голосовых и текстовых каналов;
  • информация о подключении пользователей к временным голосовым каналам;
  • данные, необходимые для работы технических функций бота.

3. Использование информации

Получаемая информация используется для работы функций SRP Voice, включая создание временных голосовых каналов, изменение лимита участников, автоматическое удаление пустых каналов и ведение технических логов.

Полученные данные не используются для рекламных рассылок и не продаются третьим лицам.

4. Хранение данных

SRP Voice не предназначен для постоянного хранения персональной информации пользователей.

Техническая информация используется только в объёме, необходимом для функционирования соответствующих функций бота.

5. Передача информации

SRP Voice не передаёт собираемую техническую информацию третьим лицам для рекламных или коммерческих целей.

6. Безопасность

Для защиты обрабатываемой информации принимаются разумные технические меры безопасности.

7. Изменения политики

Политика конфиденциальности может обновляться по мере изменения функциональности SRP Voice. Актуальная версия всегда доступна на этой странице.

8. Контакты

По вопросам, связанным с конфиденциальностью или работой SRP Voice, можно обратиться к разработчику через официальный сервер поддержки Discord.
