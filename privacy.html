Политика конфиденциальности SRP Voice

Дата обновления: 30 сентября 2026 года

1. Общие положения

SRP Voice — Discord-бот для создания и управления временными голосовыми каналами на серверах Discord.

Используя бота SRP Voice, вы соглашаетесь с настоящей политикой конфиденциальности.

2. Какие данные обрабатываются

Для работы функций бота могут обрабатываться:

  • Discord ID пользователей;
  • Discord ID серверов;
  • Discord ID голосовых и текстовых каналов;
  • информация о подключении пользователей к временным голосовым каналам;
  • техническая информация, необходимая для работы функций бота.

3. Использование данных

Получаемые данные используются исключительно для обеспечения работы функций SRP Voice, включая создание, управление и автоматическое удаление временных голосовых каналов, изменение лимитов участников и ведение технических логов.

Данные не продаются и не используются для рекламных целей.

4. Хранение данных

SRP Voice не предназначен для постоянного хранения личной информации пользователей. Технические данные используются только в объёме, необходимом для работы соответствующих функций.

5. Передача данных третьим лицам

SRP Voice не передаёт собранные технические данные третьим лицам для рекламных или коммерческих целей.

6. Безопасность

Принимаются разумные технические меры для защиты обрабатываемой информации от несанкционированного доступа.

7. Изменения политики

Политика конфиденциальности может периодически обновляться. Актуальная версия всегда размещается на этой странице.

8. Контакты

По вопросам, связанным с конфиденциальностью и работой SRP Voice, можно обратиться к разработчику через официальный сервер поддержки Discord.
